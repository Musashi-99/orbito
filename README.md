# ORBITO - RevHub Platform Site

Production website for ORBITO's product engineering services and RevHub
positioning. Built with React, Vite, TypeScript, Tailwind, and shadcn/ui.

## Local development

```sh
npm install
npm run dev
```

## Quality checks

```sh
npm run lint
npm run build
```
